# Cat Rythm Game 🐱
A fun cat rythm game made by Smallz :)

Play it here: [Not released yet, coming soon]

## Controlls (PC) 💻
W, Up -> Up Arrow
A, Left -> Left Arrow
S, Down -> Down Arrow
D, Right -> Right Arrow

## Controlls (Controller) 🎮
Left Stick Up -> Up Arrow
Left Stick Left -> Left Arrow
Left Stick Down -> Down Arrow
Left Stick Right -> Right Arrow

## About 😁
It's a rythm game where you need to click the arrow at the right time. It also has cats in it, so yea :D
